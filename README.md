# Accessible Trilingual STEM Learning Hub A full-stack, WCAG 2.1 AA-compliant educational web application built with **Python (Flask)**, **Semantic HTML5**, **CSS3**, and **Vanilla JavaScript**. Designed at the intersection of **STEM pedagogy, digital accessibility, and multilingual localization**, this project delivers interactive geometry and logic problems in **English (`en`)**, **Spanish (`es`)**, and **Brazilian Portuguese (`pt`)**, complete with **American Sign Language (ASL)** visual caption cues and high-contrast UI controls. > **🎥 Video Walkthrough:** *[Paste your 2-minute Loom walkthrough link here after recording]* --- ## 🎯 Project Purpose & Architecture Modern EdTech and enterprise SaaS platforms require software that works reliably across languages, assistive technologies, and varying connectivity environments. This application demonstrates: 1. **RESTful API Design:** A lightweight Python Flask backend serving localized lesson payloads (`GET /api/lessons`) and validating learner submissions asynchronously (`POST /api/check-answer`). 2. **Inclusive Design & WCAG 2.1 AA Compliance:** Built from the ground up with semantic landmarks, keyboard-only navigation, visible focus rings, skip links, screen-reader live regions (`aria-live="polite"`), and a dynamic High-Contrast theme toggle. 3. **Multilingual Localization (i18n):** Instant UI and content switching across English, Spanish, and Brazilian Portuguese, dynamically updating the document's `lang` attribute for screen-reader pronunciation accuracy. 4. **Scaffolded STEM Pedagogy:** Breaks down geometric proofs into progressive hints, clear visual hierarchy, and immediate step-by-step feedback. --- ## 🛠️ Tech Stack * **Backend:** Python 3, Flask (REST API, JSON serialization, query parameter filtering) * **Frontend:** Semantic HTML5, CSS3 (CSS Custom Properties, Responsive Grid), Vanilla JavaScript (ES6+ `fetch` API, DOM manipulation) * **Accessibility Standards:** WCAG 2.1 AA, WAI-ARIA live regions, keyboard focus management --- ## 🚀 Getting Started (Local Setup) ### Prerequisites * Python 3.8 or higher installed on your machine. ### Installation & Running Locally 1. **Clone the repository:** ```bash git clone https://github.com cd trilingual-accessible-stem-hub ``` 2. **Create and activate a virtual environment (recommended):** ```bash python -m venv venv # On macOS/Linux: source venv/bin/activate # On Windows: venv\Scripts\activate ``` 3. **Install dependencies:** ```bash pip install -r requirements.txt ``` 4. **Start the Flask development server:** ```bash python app.py ``` 5. **Open in your browser:** Navigate to `http://127.0.0.1:5000` --- ## 🔌 API Endpoints Reference ### 1. Retrieve Localized Lessons * **Endpoint:** `GET /api/lessons` * **Query Parameters:** `lang` (`en`, `es`, or `pt`; defaults to `en`) * **Example Request:** `GET http://127.0.0` * **Sample Response:** ```json { "language": "pt", "count": 2, "lessons": [ { "id": "geo-101", "topic": "Pythagorean Theorem", "difficulty": "Foundational", "asl_caption": "ASL Video Guide: Right triangle legs (a, b) and hypotenuse (c).", "title": "Distância no Triângulo Retângulo", "prompt": "Um triângulo retângulo tem catetos de comprimento 3 e 4. Qual é o comprimento da hipotenusa?", "hint": "Use a fórmula a² + b² = c²." } ] } ``` ### 2. Validate Learner Answer * **Endpoint:** `POST /api/check-answer` * **Request Body (`application/json`):** ```json { "id": "geo-101", "answer": 5, "lang": "es" } ``` * **Sample Response:** ```json { "correct": true, "explanation": "3² + 4² = 9 + 16 = 25. La raíz cuadrada de 25 es 5." } ``` --- ## ♿ Accessibility Checklist Implemented * [x] **Skip-to-Content Link:** Allows keyboard and screen-reader users to bypass header navigation. * [x] **Dynamic `lang` Attribute Updates:** Automatically updates `<html lang="...">` when switching between English, Spanish, and Portuguese so screen readers use the correct voice synthesizer. * [x] **High-Contrast Mode Toggle:** Uses CSS variables and `aria-pressed` states to ensure AAA-level contrast ratios (`#000000` background with `#FFFFFF` and `#FDE047` foregrounds). * [x] **ARIA Live Feedback:** Uses `role="status"` and `aria-live="polite"` so screen readers announce answer verification results immediately without stealing focus. * [x] **Keyboard-Accessible Disclosures:** Uses native `<details>` and `<summary>` elements for progressive math hints. --- ## 🔮 Future Roadmap * [ ] Integrate embedded ASL video demonstrations alongside text captions. * [ ] Add automated accessibility testing using **axe-core** and Pytho
